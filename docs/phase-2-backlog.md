# Phase 2 Backlog

- Created at: 2026-07-27
- Purpose: record tasks explicitly excluded from the quality SEO release.

The following work was not performed in this release:

- Move non-real-estate calculators elsewhere.
- Redirect URLs to `moneycalculator.co.kr`.
- Delete URLs.
- Convert URLs to 404 or 410.
- Reduce sitemap URL count.
- Reorganize site categories.
- Add new guide pages.
- Change URL slugs.

Do not decide these items without data.

Required data before any phase 2 URL or index decision:

- Naver Search Advisor page-level impressions and clicks for the most recent 90 days.
- Google Search Console page-level impressions and clicks for the most recent 90 days.
- External link status for each affected URL.
- Actual user usage for each affected calculator or guide.
- Whether the same function already exists on another owned domain.

Decision rule:

- No URL deletion, redirect, noindex, sitemap removal, or slug change should be made until the data above is reviewed and the target URL list is explicitly approved.
