## 해석

VR은 비교적 양호하므로 이번 급락을 광고 위치 전체 실패로 판단하지 않는다. 광고단가 하락과 모바일 직사각형 이미지 요청 감소를 분리해서 본다.

## 이번 PR의 보호 조치

- DAN ID를 코드에서 제거하고 Render `NEXT_PUBLIC_*` 환경변수로만 주입한다.
- 실제 DAN ID가 없으면 광고 DOM과 빈 박스를 만들지 않는다.
- 계산기 광고는 계산 결과가 렌더링된 뒤 `result_primary` 슬롯으로만 호출한다.
- 홈 첫 화면 광고와 계산기 H1 이전 광고를 제거한다.
- 모바일과 데스크톱 광고를 동시에 DOM에 넣고 CSS로 숨기는 방식을 제거한다.
- AdFit SDK는 페이지에서 한 번만 로드하고, 동일 slot key는 재요청하지 않는다.

## 모바일 직사각형 이미지 긴급 감사 메모

- 수정 전 코드에서 모바일 직사각형 이미지는 공통 `AdFitMobileRectangleBanner` 역할로 존재했다.
- 주 계산기 상세 페이지에서는 모바일 header 광고만 호출하고 큰 직사각형 역할은 꺼져 있었다.
- `/calculators`, `/guides`, guide 상세, legal 계열에서는 모바일 큰 직사각형이 호출될 수 있었다.
- 측정 노출 0이 `display:none` 초기 렌더링, SDK 측정 방식, 또는 실제 report 측정 문제인지 production DOM으로 확인해야 한다.
- 이번 PR은 이 단위를 삭제하지 않고 `NEXT_PUBLIC_ADFIT_MOBILE_RECTANGLE_IMAGE`로 보존한다. 결과 직후 `result_primary`에서 우선 선택된다.
